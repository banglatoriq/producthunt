# 🎯 Product Hunter BD

চায়না থেকে প্রোডাক্ট এনে বাংলাদেশে অনলাইনে বেচার আগে **প্রোডাক্টটা আসলে লাভজনক কিনা** আর **কে কিনবে** — এই দুটো প্রশ্নের উত্তর বের করার প্রাইভেট টুল।

পাসওয়ার্ড দিয়ে সুরক্ষিত। **AI-এর জন্য কোনো টাকা লাগে না** — সব ফ্রি প্রোভাইডার।

## ⚠️ আইডিয়া ট্যাব সম্পর্কে সবচেয়ে জরুরি কথা

AI-এর কাছে **বাংলাদেশের লাইভ সেলস ডেটা নেই**। আইডিয়া ট্যাব যা দেয় তা হলো *হাইপোথিসিস* — "এটা হয়তো চলতে পারে"। এটা প্রমাণ নয়।

সেজন্য প্রতিটা আইডিয়ার নিচে **সাতটা যাচাই বাটন** আছে, যেগুলো সরাসরি ওই প্রোডাক্টের সার্চ পেজে নিয়ে যায়:

| লিঙ্ক | কী দেখবে |
|---|---|
| **FB Ad Library** ⭐ | কোন অ্যাড কতদিন ধরে চলছে। **৩০+ দিন চলা অ্যাড = লাভজনক** — এটাই সবচেয়ে শক্ত সিগন্যাল |
| **Daraz BD** | কতজন সেলার, কত দামে, সাম্প্রতিক রিভিউ আসছে কিনা |
| **1688** | চায়নায় আসল হোলসেল দাম (চাইনিজ কীওয়ার্ডে) |
| **Alibaba** | সাপ্লায়ার, MOQ, ভেরিফিকেশন |
| **AliExpress** | ১ পিস স্যাম্পল আনা |
| **Google Trends** | বাংলাদেশে সার্চ বাড়ছে না কমছে |
| **Meesho (IN)** | পাশের বাজারে চলছে কিনা |

**নিয়ম: কমপক্ষে ৩টা সিগন্যালে একই প্রোডাক্ট না পেলে ধরবে না।** AI-এর লিস্ট শুধু ব্লাঙ্ক পেজ থেকে বাঁচায় — সিদ্ধান্ত ওই লিঙ্কগুলো দেখে নেবে।

আইডিয়া পছন্দ হলে **💰 ক্যালকুলেটরে পাঠাও** চাপো — নাম, আনুমানিক দাম আর ওজন নিয়ে মার্জিন ট্যাবে চলে যাবে।

## ফ্রি AI প্রোভাইডার — কোনটা বেছে নেবে

সাইডবার থেকে যেকোনো একটা বাছো। সব কটাই OpenAI-কম্প্যাটিবল, তাই কোড একই থাকে।

| প্রোভাইডার | key নিতে | সুবিধা | অসুবিধা |
|---|---|---|---|
| **Google Gemini** ⭐ | [aistudio.google.com/apikey](https://aistudio.google.com/apikey) | কার্ড লাগে না, বাংলা ভালো লেখে, **ছবি সাপোর্ট করে**, বড় কনটেক্সট | ফ্রি টিয়ারের ডেটা Google ট্রেনিংয়ে ব্যবহার করতে পারে |
| **Groq** | [console.groq.com/keys](https://console.groq.com/keys) | সবচেয়ে দ্রুত, কার্ড লাগে না | মডেল ক্যাটালগ ঘন ঘন বদলায়, ছবি নেই |
| **OpenRouter** | [openrouter.ai/keys](https://openrouter.ai/keys) | এক key-তে অনেক মডেল (`:free` ওয়ালাগুলো) | ফ্রি মডেলে রেট লিমিট কড়া |
| **Ollama** | [ollama.com/download](https://ollama.com/download) | **কোনো key নেই, ইন্টারনেট লাগে না, ডেটা পিসি ছাড়ে না** | পিসির RAM লাগে, ছোট মডেল বাংলায় দুর্বল |

**আমার সুপারিশ:** শুরু করো **Gemini Flash** দিয়ে — বাংলা লেখা সবচেয়ে ভালো আর ছবি আপলোড কাজ করে। কোটা শেষ হলে Groq-এ সুইচ করো (দুটো key রেখে দাও, সাইডবারে এক ক্লিকে বদলাবে)।

> ⚠️ **গুরুত্বপূর্ণ:** ফ্রি প্রোভাইডাররা নোটিশ ছাড়াই মডেল মুছে দেয় বা কোটা কমায় — কোড না বদলালেও অ্যাপ হঠাৎ কাজ করা বন্ধ করতে পারে। সেজন্য এখানে মডেলের নাম **হার্ডকোড করা হয়নি**; সাইডবারের **🔄 মডেল লিস্ট রিফ্রেশ** বাটন প্রোভাইডার থেকে লাইভ তালিকা আনে। কিছু কাজ না করলে সবার আগে ওই বাটনটা চাপো।

GEMINI_API_KEY = "AIza..."

key না দিলেও চলবে — সাইডবারে হাতে দেওয়া যায়।

## হিসাবটা কীভাবে হয় (গুরুত্বপূর্ণ)

### ল্যান্ডেড কস্ট (প্রতি পিস)

```
পণ্যের দাম   = ¥দাম × এক্সচেঞ্জ রেট
ফ্রেইট       = (ওজন গ্রাম ÷ ১০০০) × ফ্রেইট রেট প্রতি কেজি
ডিউটি        = (পণ্যের দাম + ফ্রেইট) × ডিউটি%
এজেন্ট ফি    = পণ্যের দাম × কমিশন%
ল্যান্ডেড কস্ট = পণ্য + ফ্রেইট + ডিউটি + এজেন্ট + প্যাকেজিং
```

### নেট লাভ — ১০০ অর্ডারের সিমুলেশন

এখানেই বেশিরভাগ নতুন ব্যবসায়ী ভুল করে। **অ্যাড খরচ আর ফরোয়ার্ড কুরিয়ার সব অর্ডারেই লাগে — ডেলিভারি হোক বা রিটার্ন হোক।** রিটার্ন হলে পণ্য ফেরত আসে (তাই COGS ধরা হয় না), কিন্তু অ্যাডের টাকা আর কুরিয়ারের টাকা চলে যায়।

```
ডেলিভার্ড     = ১০০ × (১ − রিটার্ন হার)
বিক্রি        = ডেলিভার্ড × সেল প্রাইস

− অ্যাড খরচ    = ১০০ × CAC                    ← সব অর্ডারে
− কুরিয়ার     = ১০০ × ফরোয়ার্ড + রিটার্ন × রিটার্ন চার্জ
− গেটওয়ে      = বিক্রি × গেটওয়ে%
− COGS        = ডেলিভার্ড × ল্যান্ডেড কস্ট
− রিটার্ন ক্ষতি = রিটার্ন × নষ্ট% × ল্যান্ডেড কস্ট

= নেট লাভ
```

### কোন সংখ্যাগুলো বাস্তবসম্মত

| ইনপুট | নিরাপদ ডিফল্ট | কেন |
|---|---|---|
| COD রিটার্ন হার | **২৫%** | বাংলাদেশে ২০–৩০% স্বাভাবিক। কম ধরলে খাতায় লাভ, পকেটে লস |
| CAC | **৩৫০–৫০০৳** | নতুন পেজে প্রথম দিকে বেশি হয় |
| মার্কআপ | **কমপক্ষে ৩x** | অ্যাড খরচ সময়ের সাথে বাড়ে, বাফার লাগে |
| ওজন | **< ৫০০ গ্রাম** | এয়ার ফ্রেইটে ভারী পণ্য মার্জিন খেয়ে ফেলে |
| প্রথম লট | **২০–৫০ পিস** | প্রুভ হওয়ার আগে বেশি নয় |

> ফ্রেইট রেট আর ডিউটি % বদলায় এবং পণ্যভেদে আলাদা। ডিফল্ট মানগুলো শুধু শুরু করার জন্য — **নিজের এজেন্ট/ফরওয়ার্ডারের কাছ থেকে যাচাই করে বসাও।**

## ফাইল কাঠামো

```
product_hunter/
├── app.py                        # মূল UI, চারটি ট্যাব
├── auth.py                       # পাসওয়ার্ড গেট, লকআউট, সেশন
├── discover.py                   # আইডিয়া জেনারেশন + যাচাইয়ের লিঙ্ক বিল্ডার
├── calc.py                       # খরচ/লাভের ইঞ্জিন (Streamlit-মুক্ত, রিইউজেবল)
├── providers.py                  # ফ্রি LLM প্রোভাইডার রেজিস্ট্রি + লাইভ মডেল লিস্ট
├── ai.py                         # প্রম্পট, JSON স্কিমা, পার্সিং ও রিট্রাই
├── store.py                      # লোকাল JSON স্টোরেজ
├── requirements.txt
├── .gitignore
├── .streamlit/
│   ├── config.toml
│   └── secrets.toml.example
└── data/
    └── products.json             # auto-তৈরি
```

**নতুন প্রোভাইডার যোগ করতে** শুধু `providers.py`-র `PROVIDERS` ডিকশনারিতে একটা এন্ট্রি বাড়াও (base_url + signup লিঙ্ক)। OpenAI-কম্প্যাটিবল হলে বাকি কোড ছুঁতে হবে না।

## ছোট মডেল সামলানোর ব্যবস্থা

ফ্রি/ছোট মডেল বড় মডেলের মতো নিখুঁত JSON দেয় না। `ai.py`-তে চার স্তরের সুরক্ষা আছে:

1. `json_object` মোড চালু (যেখানে প্রোভাইডার সাপোর্ট করে)
2. ব্যাকটিক আর ভূমিকা কেটে ব্রেস গুনে JSON বের করা
3. তাও ভাঙা থাকলে মডেলকে দিয়েই মেরামত করানো
4. তারপরও না হলে temperature কমিয়ে ৩ বার পর্যন্ত রিট্রাই
5. শেষে টাইপ নরমালাইজেশন — মডেল list-এর জায়গায় string দিলেও UI ভাঙবে না

- ১২ ঘণ্টা পর সেশন এক্সপায়ার
- সার্ভারে হোস্ট করলে **অবশ্যই HTTPS**
- ফ্রি টিয়ারে পাঠানো ডেটা প্রোভাইডার ট্রেনিংয়ে ব্যবহার করতে পারে — সাপ্লায়ারের নাম, দাম বা গোপন কৌশল পাঠিও না। পুরো গোপনীয়তা চাইলে **Ollama**।

> এটি ব্যক্তিগত টুলের জন্য যথেষ্ট। মাল্টি-ইউজার প্রোডাকশন অথ সিস্টেম নয়।

## পরে যোগ করার মতো

এখন আছে **মডিউল ১ (মার্জিন)** আর **মডিউল ৪ (পারসোনা)** — এগুলো শুধু লজিক + API, তাই ভাঙে না।

পরে আলাদা মডিউলে যোগ করা যায়:
- **Daraz স্ক্র্যাপার** — কতজন সেলার, প্রাইস স্প্রেড, রিভিউ ভেলোসিটি
- **Google Trends** — `pytrends` দিয়ে BD রিজিওনের ১২ মাসের গ্রাফ
- **FB Ad Library API** — কোন অ্যাড কতদিন চলছে
- **1688 প্রাইস লুকআপ**

স্ক্র্যাপার DOM বদলালেই ভাঙে — তাই `calc.py` বা `ai.py`-র সাথে মেশাবে না।
